git diff показывает различия между состояниями репозитория, git show выводит детали и изменения конкретного коммита, а git log отображает историю коммитов — список с метаданными, который можно фильтровать и дополнять патчами или статистикой. git log -S ищет коммиты, в которых изменилось количество вхождений заданной строки, а git blame показывает, кто и в каком коммите последним изменил каждую строку файла.
