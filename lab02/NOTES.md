Git-распределенная система контроля версий, работает локально на компьютере.

GitHub-облачный сервис для хранения Git-репозиториев и совместной работы.

Git-инструмент, GitHub-платформа

git diff --staged - то, что я уже подготовила к коммиту.

Первая- показывает разницу до git add, вторая-после.

Использованные команды:Показывает состояние: на какой я ветке,какие файлы изменены, какие в индексы, какие не отслеживаются, синхронизирована ли я с удаленным репозиторием. git diff- сравнивает рабочую папку с индексом- что изменено, но еще не добавлено через git add. git diff --staged -сравнивает индекс с последним коммитом-что именно попадет в следующий коммит.
