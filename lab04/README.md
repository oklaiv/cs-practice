\# Лабораторная 4. Анализ журнала наблюдений



Читает журнал со stdin, разбирает строки вида `город;температура;дата`,

считает среднюю температуру по городам и определяет самый тёплый город.



\## Файлы



\- `stats.py` — чистые функции: разбор, валидация, агрегация.

\- `main.py` — точка входа: чтение stdin, вывод отчёта.

\- `test\_stats.py` — тесты на pytest.
